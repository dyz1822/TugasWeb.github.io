Selamat Datang di Website Belajar Web! Halaman ini dibuat untuk mempelajari dasar-dasar pemrograman web, khususnya HTML dan CSS sesuai materi Pertemuan 3.

HTML (HyperText Markup Language) berperan sebagai fondasi atau batu bata untuk membangun kerangka dan struktur halaman web. Tag dasar HTML terdiri dari <!DOCTYPE html>, <html>, <head>, dan <body>.

CSS (Cascading Style Sheets) berfungsi untuk mengatur tampilan dan memisahkan konten dari desain visual. Dengan CSS, kita dapat mengatur warna latar belakang (seperti background merah marun ini), jenis font, jarak tata letak, hingga posisi header dan footer agar tampilan web menjadi rapi dan menarik.
